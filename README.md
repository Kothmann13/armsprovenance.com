# armsprovenance.com

Static website for Arms Provenance, the home of Security Provenance's firearm record-keeping software
(the Arms Provenance Android app, plus the products on the workbench). Plain HTML/CSS, no JavaScript,
no trackers, no third-party resources. Strict CSP (no inline styles or scripts).

Pages: index.html (product hub), app.html (Android app), privacy.html, terms.html and eula.html (drafts, noindex), 404.html.

Pages are generated by the scripts in /workspace/arms-provenance-page/src (run with AP_SITE=aps):
hub.py (index + app via ap_page.py), legal.py, privacy_aps.py, notfound_aps.py.

Hosting (not set up yet): GitHub Pages from this repo's main branch with the CNAME file (armsprovenance.com).
